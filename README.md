# 호수의 어부들 : 공유지의 비극 (교육용 웹 시뮬레이터)

이 시뮬레이터는 중·고등학교 사회 수업의 **[시장 실패]** 단원 중 **"공유 자원의 남용과 시장 실패(공유지의 비극)"** 개념을 학생들이 게임 형식을 통해 직접 체험하고 깨달을 수 있도록 돕는 교사용 전자칠판 최적화 웹 애플리케이션입니다.

---

## 🎮 프로젝트 소개

- **개발 목적**: 개인의 합리적 선택(수익 극대화)이 사회 전체적으로는 비합리적인 결과(자원 고갈 및 파산)를 초래하는 '공유지의 비극' 현상을 직접 체험합니다.
- **수업 형태**: 교사가 교실 전자칠판(또는 대형 스크린)에 본 화면을 띄워 놓고 진행하며, 각 학생 모둠은 종이 활동지에 출항시킬 배의 척수를 적어 교사에게 제출하면, 교사가 이를 입력하여 시뮬레이션을 수행합니다.
- **주요 특징**:
  - **🖥️ 듀얼 모니터 발표자 모드 (Presenter & Projector View)**: 교사 노트북 화면(입력용 제어창)과 학생용 전면 빔프로젝터 화면(시각화 및 모달 결과창)을 다르게 미러링하는 신기술을 구현했습니다.
  - **🔒 비밀 입력 가림막 (Input Masking)**: 단일 모니터 진행 시에도 학생들에게 척수 입력 과정을 감출 수 있는 반투명 마스크 레이어와, 교사의 **임시 엿보기(Inspect) 클릭 기능**을 추가했습니다.
  - **완전 오프라인 구동**: 인터넷이나 외부 DB(Firebase) 연동 없이 **순수 단일 폴더(HTML5/CSS3/JS)** 구조로 인터넷이 안 되는 교실에서도 100% 무결하게 작동합니다.
  - **⌨️ 스마트 입력 UX**: 교사용 무선 키보드로 손쉽게 제어할 수 있도록 단축키(`1`, `2`, `3`), 되돌리기(`Backspace`), 실행(`Enter`) 및 자동 다음 행 포커스를 연계 지원합니다.

## 🚀 실행 방법

본 프로젝트는 순수 HTML, CSS, JavaScript로 구현되어 있습니다.

1. 저장소의 `index.html` 파일을 브라우저(Chrome, Edge 권장)로 실행합니다.
2. **듀얼 모니터 사용 시 (추천)**:
   - 교사 노트북과 교실 프로젝터(전자칠판)를 디스플레이 **"확장"** 모드로 설정합니다.
   - 브라우저로 `index.html`을 연 후, 좌측 상단 헤더의 **`🖥️ 빔프로젝터용 화면 (학생용) 띄우기`** 버튼을 클릭합니다.
   - 새로 열린 학생용 팝업 창을 마우스로 드래그하여 전면 빔프로젝터 스크린으로 보낸 뒤, 전체 화면 모드(단축키: `F11`)로 띄웁니다.
   - 교사는 노트북 화면에서 입력을 비밀스럽게 제어하고, 학생들은 대형 화면을 보며 실시간으로 유영하는 물고기와 턴 결과 팝업창을 즐겁게 감상합니다.

## 📝 수업 준비 및 게임 규칙

### 1. 학생 모둠 구성 및 준비물
- 학급 학생들을 **5개 내외의 모둠**(최소 2모둠, 최대 8모둠)으로 나눕니다.
- 각 모둠에 종이 활동지(또는 개인 화이트보드)를 배부하여 매 턴 출항시킬 배의 수를 비밀리에 적어 제출하도록 합니다.

### 2. 게임 기본 규칙
- **초기 물고기**: `min(모둠 수 × 30마리, 200마리)`
- **환경 수용력**: 200마리
- **출항 가능 척수**: 모둠별 매 턴 **1척, 2척, 3척** 중 선택
- **포획량**: 배 1척당 **5마리**의 물고기를 포획하며, 포획한 물고기 수만큼 모둠 수익금(점수)이 누적됩니다.
  - *예: 3척 출항 → 15마리 포획 → 수익금 +15점*
- **번식 로직**: 턴이 끝났을 때 호수에 남은 물고기의 **80%가 번식**하여 다음 턴을 시작합니다. 번식 후 최대 개체수는 200마리입니다.
- **자원 부족 및 고갈**:
  - 전체 모둠이 요구한 포획량이 현재 물고기 수보다 많을 경우, 남은 물고기를 모둠별 출항 배 척수 비율로 **비례 배분**하여 가져갑니다.
  - 호수 물고기가 **0마리**가 되면 번식이 멈추며 **호수 고갈 상태**가 됩니다.

## 👩‍🏫 교사용 진행 순서 (추천 시나리오)

### 1단계: 자유 방임 (1~3턴) - "개인의 선택에 맡기기"
1. 초기 설정 화면에서 모둠 수(기본 5모둠)를 설정하고 9턴 게임을 시작합니다.
2. **자유 방임 모드** 상태에서 학생들에게 "우리 모둠의 이익을 가장 크게 만들어 보라"고 안내합니다.
3. 학생들이 종이에 몰래 적어 제출한 배의 척수를 입력합니다.
   - 💡 **교사 꿀팁 (단축키)**: 키보드 `1`, `2`, `3`을 누르면 포커스된 모둠에 배 척수가 자동 지정되며 다음 모둠으로 포커스가 자동 진행됩니다. 오입력 시 `Backspace`를 누르면 복구됩니다.
   - 💡 **비밀 입력 가림막 (단일 모니터 수업 시)**: 프로젝터를 띄우고 교실에서 단일 창으로 진행할 때는 헤더의 **`🔒 비밀 입력 켜기`** 버튼을 클릭하거나, 키보드의 **`H`** 키(한글 상태에서 **`ㅗ`** 키도 가능)를 누르세요.
     - 입력 칸이 반투명한 `🔒 입력 대기` 마스크로 가려집니다. 
     - 모둠 척수를 숫자로 쳐 넣어도 학생들에겐 보이지 않고 황금색 `🔒 입력 완료 (클릭하여 확인)` 배지만 노출됩니다.
     - **교사 확인**: 교사가 마스크를 **클릭**하면 일시적으로 해당 행의 마스크가 숨겨져 실제 척수를 교사만 몰래 슬쩍 볼 수 있습니다. 재클릭하면 다시 가려집니다.
4. 총 출항량에 따라 물고기 개체수가 어떻게 변하는지 관찰합니다.

### 2단계: 자율 협약 (4~6턴) - "우리 다 같이 약속해요"
1. 4턴 안내창이 열리면 교사가 3분 타이머를 시작합니다.
2. 학생들은 모둠별로 모여 어떻게 호수를 지킬지 협의합니다. 보통 **"다 같이 1척씩만 출항하자"**는 약속을 맺게 됩니다.
3. 자율 협약 단계는 자동으로 활성화되며 약속에는 강제력이 없습니다.
4. 약속 준수 여부와 호수 및 모둠 점수의 변화를 비교합니다.

### 3단계: 정부 규제 및 감시 실패 (7~9턴) - "법과 집행의 관계"
1. 무너진 협약과 자원 고갈 위기를 배경으로, 교사는 시장 실패를 보완할 **법적 강제 제도**를 시뮬레이션합니다.
2. 7턴부터 법정 출항 한도를 1척 또는 2척으로 정합니다. 한도 위반 선택은 가능하지만 적발되면 초과 1척당 7점의 벌금이 부과됩니다.
3. 결과에서는 미적발 모둠의 선택·포획량·벌금·누적 점수가 모두 가려집니다.
4. 교사는 `🔍 조사하기`로 미적발 모둠을 조사할 수 있으며, 위반이 확인되면 그 시점에 벌금이 적용됩니다.
5. 법의 존재뿐 아니라 적발 가능성과 집행력이 행동에 어떤 영향을 미치는지 토론합니다.

### 수업 중 안전 기능
- 턴 결과창에서는 숫자·Enter 단축키가 비활성화되어 중복 실행을 방지합니다.
- 매 턴 기록은 브라우저에 자동 저장되며 시작 화면의 **이전 수업 이어하기**로 복구할 수 있습니다.
- 결과창의 **이번 턴 되돌리기**로 오입력한 턴을 다시 입력할 수 있습니다.
- 진행 기록은 CSV 또는 인쇄/PDF로 저장할 수 있습니다.

## 💬 수업 후 토론 질문 (Discussion Cards)

1. **개인의 합리성 vs 사회적 합리성**
   - "우리 모둠이 수익을 위해 3척을 낸 것은 합리적인 결정이었는가?"
   - "모든 모둠이 합리적으로 행동한 결과가 왜 공유지 파괴라는 비합리적인 사회적 결과를 낳았는가?"
2. **비극의 책임 소재**
   - "호수가 고갈되었다면, 3척을 계속 낸 모둠에게만 전적인 책임이 있는가? 제도를 마련하지 못한 규칙에 책임이 있는가?"
3. **해결 방안의 비교 평가**
   - "자율적인 약속(자율 협약)과 법적 강제력(규제, 벌금) 중 무엇이 공유 자원 보전에 더 실효성이 있었는가?"
   - "우리가 살아가는 현실 속에서 공유지의 비극 현상(예: 쓰레기 무단 투기, 기후 변화, 물 남용, 공공 자전거 파손 등)을 해결하기 위해 어떤 제도적 장치와 도덕적 자성이 필요할까?"
